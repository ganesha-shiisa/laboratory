ユークリッドの互除法 ビジュアライザー Math

比率に応じた長方形・正方形の再帰的幾何分割を可視化。画面サイズ連動のレスポンシブ表示およびパラメータの動的変更に対応。

使用技術: HTML5 Canvas / JavaScript (Vanilla)
対数螺旋 ビジュアライザー Generative Art

正多角形の各辺を一定比率で縮小・回転させながら内側に再帰描画することで対数螺旋を生成。頂点数・回転角・ギャップや配色のインタラクティブな変更に対応。

使用技術: HTML5 Canvas / JavaScript (Vanilla)
